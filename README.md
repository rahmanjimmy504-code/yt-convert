# YT Convert

A clean, fast YouTube to MP3 & MP4 converter website built with Next.js and shadcn/ui.

## How It Works

1. Paste any YouTube URL
2. See the video thumbnail and info instantly
3. Click a converter button — your URL is auto-copied to clipboard
4. Paste it on the converter site, pick your quality, and download

## Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS 4** + **shadcn/ui**
- **YouTube oEmbed API** for video
